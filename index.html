Method

How the tools are built

My role

  • I choose the learning problem, write the competencies, and design the steps a student moves through.
  • I write or review all of the science content and check every answer key before students see it.
  • I test each tool in my own courses and revise it based on how students actually use it.

The role of AI

  • AI tools write and debug the software from my specifications.
  • AI also runs automated checks, such as simulating a full term of practice to confirm that review questions get harder as planned.
  • Each tool is a single web page, which keeps it free, easy to share, and easy for another instructor to adapt.

Access and privacy

  • Tools are designed to meet WCAG 2.2 AA, with keyboard access and screen reader labels.
  • There are no logins and no servers. Student progress is saved only in the student's own browser.
  • Tools embed in Canvas and other learning management systems.
